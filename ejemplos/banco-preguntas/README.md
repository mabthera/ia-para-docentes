# Ejemplos de preguntas GIFT y Moodle XML

Esta carpeta reúne muestras de preguntas basadas en el mito de la caverna. Está organizada por formato para facilitar la descarga y las pruebas de importación.

- `gift/`: ejemplos individuales y un banco completo en texto plano.
- `xml/`: ejemplos individuales y un banco completo Moodle XML.
- `recursos/`: imagen utilizada por el ejemplo de arrastrar y soltar sobre una imagen.
- `gift/modelo-largo-cuestionario.md`: prompt extenso para solicitar un cuestionario GIFT; adapta curso, objetivo y contenido antes de utilizarlo.
- `index.html`: catálogo navegable con descripción de los archivos y precauciones de importación.

Los ejemplos ilustran sintaxis; comprueba cada pregunta, respuesta, puntuación y retroalimentación antes de llevarla a un curso real. Algunos tipos de pregunta dependen de la configuración o de plugins instalados en el Moodle de destino. Importa primero una muestra pequeña en una categoría de prueba.
