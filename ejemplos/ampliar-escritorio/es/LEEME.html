Un proyecto con instrucciones y una skill

Proyecto ficticio para la formación. Los materiales docentes son HTML completos; AGENTS.md y SKILL.md conservan el formato que reconocen las aplicaciones.

Qué vamos a conservar y qué vamos a reutilizar

Este proyecto continúa la secuencia ficticia de porcentajes de 2.º de ESO. Separa las reglas comunes del proyecto de la receta que utilizaremos para preparar boletines. Los apuntes y la planificación son los mismos documentos completos de la práctica inicial.

AGENTS.md contiene decisiones estables: idioma, fuentes de la unidad, conservación de originales, separación entre ficha y respuestas y lugar de entrega. SKILL.md describe el procedimiento de una tarea concreta: leer las fuentes pertinentes, graduar ejercicios, aplicar una referencia de formato y entregar dos archivos revisados.

Documentos del proyecto

  • Skill para preparar boletines

  • Planificación docente

Cómo probarlo

  1. Descomprime el ZIP y abre únicamente la carpeta de trabajo que contiene AGENTS.md. El paquete prepara la estructura de proyecto usada por Codex y Antigravity.
  2. Abre un chat nuevo y pide que identifique las instrucciones que ha cargado, las fuentes disponibles y la carpeta donde guardará los resultados. Contrasta esa explicación con los archivos.
  3. Pide que use la skill boletin-matematicas para crear seis ejercicios de porcentajes con solucionario separado.
  4. Abre ambos HTML y revisa que se conservan los objetivos, que los cálculos son correctos y que la ficha del alumnado no contiene las respuestas.
  5. Si has conseguido un resultado útil, pide otra ficha de la misma unidad con nuevos datos. La skill debe conservar el proceso y adaptar el contenido, no repetir literalmente la plantilla.

La plantilla incluida es una ficha de ejemplo completa, con ejercicios concretos. Sirve para observar la organización visual; el contenido nuevo debe responder al encargo y a las fuentes. La carpeta de salidas comienza vacía.

Adapta el método a tu aplicación

Codex y Antigravity reconocen la ubicación de skills .agents/skills/. En Claude Code la ubicación de proyecto documentada es .claude/skills/: mueve allí la carpeta boletin-matematicas y comprueba qué instrucciones de proyecto carga tu versión. Claude Code utiliza CLAUDE.md y también admite AGENTS.md según la versión y la configuración.

No se han configurado conexiones con servicios externos en este paquete. Si después añades Drive, ElevenLabs o Cartesia, tendrás que configurar esa conexión y sus permisos en tu aplicación. Una receta o una regla escrita en un archivo no habilita por sí sola una cuenta, una API ni un servicio.

Revisa también el acceso del asistente a otras carpetas: las instrucciones de este proyecto orientan su trabajo, pero no sustituyen los permisos técnicos del apartado anterior.
